The first preview of ssbm-rs: Super Smash Bros. Melee running natively, from your own copy of the game.

## Get started

1. Download the file for your system:
   - **Windows 10 or 11 (64-bit):** `ssbm-rs.exe`
   - **macOS 11 or later (Apple silicon or Intel):** `ssbm-rs-macos.zip`. Unzip it and move `ssbm-rs.app` to Applications.
   - **Linux (x86-64):** `ssbm-rs-x86_64.AppImage`. Mark it executable (in its file properties, or `chmod +x`).
2. Open it. The first time, it asks for your disc image of Melee, NTSC version 1.02 (game ID GALE01, revision 2), as an `.iso`, `.rvz`, `.ciso` or `.gcz` file. It remembers it, so later launches go straight to the game.

The release contains no game data. Other versions of Melee and modded discs aren't supported.

## The first launch on each system

These builds aren't signed by a paid certificate, so each system asks once whether to trust them:

- **Windows:** if SmartScreen says "Windows protected your PC", choose **More info**, then **Run anyway**.
- **macOS:** if it says Apple can't verify the app, open **System Settings → Privacy & Security** and choose **Open Anyway** next to ssbm-rs.
- **Linux:** the disc picker uses your desktop's file chooser (any major desktop has one); message boxes use `zenity` when it's installed.

## Playing

Keyboard, gamepads and GameCube controllers through a Wii U-style adapter all work; the [README](https://github.com/itsarahtonin/ssbm-rs/blob/main/README.md#controls) has the controls. On Windows, the adapter needs the WinUSB driver (installed with Zadig, as for Dolphin). Your memory card and the remembered disc live in an `ssbm-rs` settings folder (`%APPDATA%\ssbm-rs` on Windows, `~/.config/ssbm-rs` elsewhere).

## What to expect

This is a development preview. The game's code is translated into Rust and checked against the original, but that verification is still in progress, and the renderer approximates some of the GameCube's graphics hardware. The Windows build has been played the most; the macOS and Linux builds are new. If something looks, sounds or plays wrong, please report it with your system and what you were doing. See [verification and limitations](https://github.com/itsarahtonin/ssbm-rs/blob/main/docs/verification.md) for details.
