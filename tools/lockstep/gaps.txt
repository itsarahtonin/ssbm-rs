# as explained. One block per line, by its function and its offset in it, with what keeps runs
# out and the evidence for it:
#
#     FUNCTION+OFFSET KIND # evidence: the analysis, or the callers and the values they pass
#
# KIND is dead (no value that reaches the branch takes it), dev (developer-only code that nothing
# in the game turns on) or hw (code that only hardware the SDK layer leaves out runs). A block
# that odd state can reach, such as a null check the game never trips, belongs to probes and
# mutated checks instead, not here.
#

# verified by probes.
