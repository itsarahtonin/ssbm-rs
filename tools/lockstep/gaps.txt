# The gap ledger: blocks of the original that no run can reach, which coverage.py --gaps counts
# as explained. One block per line, by its function and its offset in it, with what keeps runs
# out and the evidence for it:
#
#     FUNCTION+OFFSET KIND # evidence: the analysis, or the callers and the values they pass
#
# KIND is dead (no value that reaches the branch takes it), dev (developer-only code that nothing
# in the game turns on), fail (code that runs only once the game has failed: exception handlers,
# crash dumps, exit), hw (code that only hardware the SDK layer leaves out runs, or that the SDK
# layer stands in for) or oracle (provisional: code every game runs that lockstep cannot check,
# because it never returns or runs as an exception handler; the replay rotation's frame
# comparison with Dolphin covers what it does). A block that odd state can reach, such as a null
# check the game never trips, belongs to probes and mutated checks instead, not here.
#
# A function whose name other units also use is named UNIT:FUNCTION (its unit as the decomp's
# asm tree names it, such as dolphin/axfx/reverb_hi:HandleReverb).
#
